Metodología y fuentes

Este mapa recopila avisos de bomba (amenazas, evacuaciones preventivas, falsas alarmas y artefactos confirmados) en países europeos.

  • Solo se incluyen avisos con enlace a una fuente oficial: policía, ministerio del Interior, protección civil u organismo público competente. No se usan periódicos, tabloides ni redes sociales.
  • Cada ficha indica localidad, lugar, fecha y hora, estado y el enlace a la publicación oficial.
  • Los datos están incompletos por diseño: muchos avisos no se hacen públicos, se retiran o no se confirman.
  • Las falsas alarmas se etiquetan como tal y no deben interpretarse como amenazas reales.
  • No se publican detalles operativos sensibles.

Los datos actuales son una demostración con avisos ficticios. No son noticias reales.

Cómo añadir un aviso

Los avisos se editan en data/incidents.json. Cada registro debe incluir coordenadas, fecha/hora ISO 8601 con zona horaria y un enlace a la fuente oficial. Consulta el README para el esquema completo.
