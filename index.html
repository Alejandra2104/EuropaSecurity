Metodología y fuentes

Este mapa recopila avisos de bomba (amenazas, evacuaciones preventivas, falsas alarmas y artefactos confirmados) en países europeos.

  • Cada aviso puede incluir varias fuentes: nota de policía, fuente oficial, declaración oficial y nota de prensa.
  • La nota de policía procede de una publicación policial; la fuente oficial, de un organismo público competente; la declaración oficial es una manifestación de una autoridad recogida por un medio; la prensa es un artículo periodístico y no equivale a confirmación oficial.
  • Cada ficha indica localidad, lugar, fecha y hora, estado, resultado, fuentes y enlaces. Las falsas alarmas y los avisos descartados se señalan de forma expresa.
  • Los datos están incompletos por diseño: muchos avisos no se hacen públicos, se retiran o no se confirman.
  • El balance compara falsas alarmas declaradas, avisos descartados sin riesgo, amenazas reales confirmadas y casos pendientes. El porcentaje principal se calcula sobre los casos resueltos; los pendientes se muestran aparte.
  • El perfil provisional del autor o autores es un análisis preliminar basado en las fuentes. No identifica a personas, no formula acusaciones y respeta la presunción de inocencia.
  • No se publican detalles operativos sensibles ni datos personales.

Los avisos están contrastados con la fuente enlazada; el filtro «Fuente» permite separar nota de policía, fuente oficial, declaración oficial y prensa. Cuando la fuente solo indica el día, la ficha no muestra una hora inventada; si la hora es aproximada, se señala expresamente.

Cómo añadir un aviso

Los avisos se editan en data/incidents.json. Cada registro debe incluir coordenadas, fecha/hora ISO 8601 con zona horaria y al menos una fuente. Puede llevar una fuente principal en source y una lista en sources con type igual a police, official, official_statement o press. El análisis se edita en data/analysis.json. Consulta el README para el esquema completo.
